# Mechanoid Upgrades - Militor Pack Recipe

Mechanoid Upgrades 모드의 서브모드로, "밀리터 강화장치(Militor Upgrade Pack)"의 제작법을 추가해 주는 모드.

보다 강력한 밀리터를 만들고 싶었는데 이 아이템이 non-craftable이라 대충 만듦.

## 제작법

* 나노 구조화 칩 x1
* 플라스틸 x30
* 우라늄 x15
* 금 x10

## 밸런스 영향
